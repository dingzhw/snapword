# 词哒 · SnapWord 演进路线图 (Roadmap)

本项目旨在为小学中高年级（尤其是存在跨教材断层、音形脱节、依赖死记硬背的英语初学者）提供一套 **安静、有趣、零挫败、最终落回纸笔独立书写** 的开源家庭伴学工作台。

---

## v0.1.0 — 核心趣味伴学工作台 MVP（已完成）
- [x] **无回声高对比全屏工作台**：专为「独立手机视频 + 远程桌面同屏带教」与平板/桌面端优化，零吵闹战斗音效。
- [x] **四大趣味学习机关**：咔嗒磁吸拼块、三槽摇奖造句机（含同屏口语黑板）、抓拼写臭虫侦探、铜/银/金三阶成长徽章。
- [x] **按需可选支架**：区分整词读音、视觉拼写难块、构词记忆与短语真实词界，支持会写的词一键跳过屏幕拼写直达纸写。
- [x] **两遍红笔纸笔闭环**：先盲查自己纸面（大写/空格/难块），再亮答案圈改并遮盖重写；严格区分首答、自查与订正。
- [x] **防污染学习账本**：隔离「家长演练试用」与「学生正式作答」，内置 `D+1 / D+3 / D+7` 课前抽查队列、快速文本排课与备份预览恢复。
- [x] **便携单文件构建与自动化验证**：`tools/build.py` + `tests/verify_snapword.cjs`。

## v0.2.0 — 孩子友好首页（已完成）
- [x] **单主卡「今天练这一课」**：一屏一张卡讲清第几课、中文主题、今天练哪几个词、时长、已会进度，只保留一个主 CTA。
- [x] **「换一组」分阶段卡片选择器**：第一次来 / 秋假闯关 / 课本 Unit 6 / 必背句子，替代原来 11 项混排的教材下拉框。
- [x] **排课术语收进「家长微调」**：三栏分配、超容量候选、重点句快捷入口默认折叠，孩子端不再出现「本轮纸写 / 下轮候选」。
- [x] **移动端顶栏瘦身**：单行横滑导航，390px 首屏可见主卡与开始按钮。

## v0.3.0 — 全面无纸化网页闯关与多模型 AI 智能伴学引擎（已完成）
- [x] **彻底取消纸笔中转**：全流程网页盲打闯关、字符级拼写差异高亮、10 秒当场遮盖盲打订正、自动结算金银铜勋章与 `D+1 / D+3 / D+7` 复测日历。
- [x] **多模型 AI 接口（`SnapAI`）**：支持 OpenAI（默认 `gpt-6.2-sol`）、Gemini、DeepSeek、本地 LM Studio 及自定义兼容接口；支持读取模型列表选择、保持默认或手动输入；密钥本机物理隔离不随备份导出。
- [x] **三档难度与嵌入式微游戏**：初学·简单 / 温习·普通 / 考核·挑战 / 智能自适应，内置音义闪电消消乐、磁吸拆拼与 AI 五上动态变式句挖空。
- [x] **五上 Unit 6 词表 1–10 全默支持**：星号与非星号词全量必默排课（全 10 词连闯 + 前后半场 5+5）。

## v0.4.0 — 外部磁盘文件备份与学情周报（计划中）
- [ ] **File System Access API 授权备份**：支持桌面 Chromium 浏览器绑定本地外部 JSON 备份文件，清晰展示内部存储与外部备份各自状态，妥善处理重开浏览器后的权限重确认。
- [ ] **一页纸轻量双周复盘简报**：直观对比基线词与最新隔日纸写稳定度，一键导出纯文本家庭复盘小结。
